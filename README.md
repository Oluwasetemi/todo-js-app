# JS TODO APP

A simple and interactive Todo application built with vanilla JavaScript, HTML, and CSS.  
This project is designed for teaching purposes and demonstrates core concepts such as DOM manipulation, local storage, modular JavaScript, and responsive design.

## Features

- **Create Todo Lists:** Organize your tasks into multiple lists.
- **Add, Edit, and Delete Todos:** Manage your tasks easily.
- **Filter Todo Lists:** Search and filter your todo lists by name.
- **Mark Todos as Completed:** Track your progress by marking tasks as done.
- **Persistent Storage:** All data is saved in your browser's local storage.
- **Responsive Design:** Works well on both desktop and mobile devices.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (optional, only if you want to use a local server)
- A modern web browser (Chrome, Firefox, Edge, etc.)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/todo-js-app.git
   cd todo-js-app
   ```

2. **Open the app:**
   - Simply open `index.html` in your browser.
   - Or, use a local server (recommended for some browser features):
     ```bash
     npx serve .
     # or
     python -m http.server
     ```

## Usage

- **Add a Todo:** Enter a task and click "Create Todo".
- **Create/Manage Lists:** Use the UI to create and switch between different todo lists.
- **Search Lists:** Use the search bar to filter your todo lists by name.
- **Mark as Completed:** Click on a todo to mark it as done.
- **Delete Todos/Lists:** Remove tasks or entire lists as needed.
